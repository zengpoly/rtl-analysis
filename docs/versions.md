# 版本说明

## 如何选择

| 项目 | V1：`main` | 知识构建预览版：`knowledge-build` |
|---|---|---|
| 默认分析 | 源码 + 任务内 Runtime | 显式构建知识；查询复用适用的已发布知识，缺口回到源码 / Runtime |
| 是否需要预建知识 | 否 | Build1 / Build2 工作流需要；普通源码查询可独立使用 |
| Build1 | 实现仍在源码中，默认流程不调用 | 生成编译器支撑的结构候选及派生 Manual |
| Build2 | 默认流程不调用 | 生成和恢复语义草稿，保留未知与审核状态 |
| 可用知识 | 默认不读取 | 必须身份匹配、当前有效，语义还须经过适用的审核与发布 |
| 标签 | `v1.0.0` | `knowledge-preview-1` |

Build1 的结构事实不能证明行为语义；Build2 的 `DRAFT_UNREVIEWED` 或自检通过草稿不能作为已审核知识。知识不足、失效或不能唯一定位目标时，保留缺口并按明确范围读取源码和 Runtime 证据。
