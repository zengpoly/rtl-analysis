# RTL 分析需求

面向工程师的默认流程是：准备 RTL 工程 → Agent 安装和确认配置 → 读取源码及调用 Runtime 工具 → 回答问题并引用证据。操作入口见 [使用说明](../quickstart.md)。

- 分析源码保持只读；不同工程的源码、配置和结果独立保存。
- 使用锁定版本的现成工具，不自行实现 RTL parser、elaborator 或分析算法。
- Runtime 查询按任务创建 PySlang Compilation，复用后释放，不要求预构建知识库。
- 结论引用源码或工具证据，保留未知、截断和适用范围。
- 离线安装需要预先准备依赖和兼容环境；Git 仓库不携带工具二进制或模型。
