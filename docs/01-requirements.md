# RTL 知识构建预览需求

用户先配置只读 RTL Project 和明确 Analysis Scope，再构建可复用结构知识、生成有界语义草稿，并在查询时复用当前有效、已发布的材料。

- Build1 生成编译器支撑的结构候选、机器回执与派生 Manual，保留 Source Evidence 和 Build 身份。
- Build2 对明确范围规划小块，分阶段保存 evidence、draft、review 与组合自检，支持核验后恢复；产物保持未审核草稿。
- Query 区分充分适用知识、部分上下文和回退，只补明确缺口；无有效知识时支持源码 / Runtime。
- Manual 是知识的只读派生视图，task 草稿预览不能冒充正式发布。
- 用户源码、凭据、工具缓存和实际工程产物不进入 Git；本次提供源码和标签。

操作入口为[使用说明](../quickstart.md)。签核、全工程覆盖、模型效果提升和跨环境部署需要独立验证。
